# CDE4301 Interim Report: Automated Box Formation and Sealing for High-Mix Kitting

NUS CDE4301 Innovation & Design Capstone, Semester 1, AY2026/27.
Project code: ASI-401.

Live report: https://manfredlow.github.io/CDE4301/

## Project
Automated box forming (WP2) and seal application (WP4) for kitting at CEVA
Logistics' Blue Hub, under the SIT-CEVA Joint Lab. One SKU recipe, selected
once, sets up both stations without manual changeover.
